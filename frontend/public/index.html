⚡ EC คืออะไร? pH คืออะไร?
EC (Electrical Conductivity) = ค่าการนำไฟฟ้าของน้ำ บอกว่ามีสารอาหารละลายอยู่มากแค่ไหน
  • EC สูง → สารอาหารเยอะ (ต้นไม้อาจรากไหม้)
  • EC ต่ำ → สารอาหารน้อย (ต้นไม้โตช้า)
  • ค่าที่ดีสำหรับมะเขือเทศ: 1.5 - 3.0 mS/cm
pH = ค่าความเป็นกรด-ด่างของน้ำ มีผลต่อการดูดซึมสารอาหาร
  • pH ต่ำกว่า 5.5 → เป็นกรด (ธาตุเหล็กดูดซึมมากเกิน)
  • pH สูงกว่า 7.0 → เป็นด่าง (ธาตุบางอย่างดูดซึมไม่ได้)
  • ค่าที่ดีสำหรับมะเขือเทศ: pH 5.5 - 6.5
🍅 ค่า EC ที่แนะนำตามระยะการเติบโต
💡 ระบบนี้เริ่มใช้งานตั้งแต่ระยะ "ย้ายกล้าลงระบบ" เป็นต้นไป — ต้นมะเขือเทศควรโตมีใบจริง 4-6 ใบ ก่อนย้ายเข้าระบบเพื่อเลื้อยตามโครง
ระยะ ระยะเวลา EC (mS/cm) pH หมายเหตุ
💧 เพาะเมล็ด 5-14 วัน 0 (น้ำเปล่า) 6.5 ใช้น้ำสะอาดเท่านั้น
🌱 ต้นกล้า 14-21 วัน 0.8 - 1.2 6.0 - 6.5 เริ่มให้อาหารเบาๆ
🪴 ย้ายกล้าลงระบบ 7-14 วัน 1.5 - 1.8 6.0 - 6.3 ⭐ เริ่มใช้ระบบ — ปรับตัวในโครง
🌿 เร่งต้น/เลื้อย 28-42 วัน 2.0 - 2.5 5.8 - 6.2 ใส่ปุ๋ยเต็มที่ จัดเลื้อยตามโครง
🌸 ออกดอก 20-30 วัน 2.5 - 3.0 5.8 - 6.2 เพิ่ม P-K เสริม ช่วยผสมเกสร
🍅 ติดลูก 40-60 วัน 3.0 - 3.5 5.8 - 6.2 สารอาหารสูงสุด ผลกำลังสุก
🎯 เก็บผล ต่อเนื่อง 2.5 - 3.0 5.8 - 6.0 เก็บทุก 6-12 วัน ลดน้ำก่อนเก็บ
💧 การจัดการน้ำในถัง
  • ใช้น้ำกรอง RO หรือน้ำที่ EC ต่ำกว่า 0.3 จะดีที่สุด
  • เปลี่ยนน้ำในถังทุก 7-14 วัน เพื่อป้องกันเชื้อสะสม
  • อุณหภูมิน้ำที่ดี: 18-25°C
  • น้ำร้อนเกิน 30°C → ออกซิเจนละลายน้อยลง → รากเน่าได้
  • ถ้าระดับน้ำต่ำกว่า 25% ควรเติมน้ำทันที!
🧪 Nutrient A & B ผสมยังไง?
  • ห้ามผสม A กับ B โดยตรง! ต้องละลายแยกกันในน้ำก่อน
  • เริ่มจากเติม A ก่อน → คนให้เข้ากัน → แล้วค่อยเติม B
  • อัตราส่วนปกติ: A : B = 1 : 1 (เท่ากัน)
  • หลังผสมเสร็จ → วัด EC ดูว่าได้ตามเป้าหรือยัง
  • ถ้า EC สูงเกิน → เติมน้ำเปล่าเจือจาง
  • ถ้า EC ต่ำเกิน → เติม A+B เพิ่มทีละนิด
⚙️ ระบบปั๊มทำงานยังไง?
  • Pump A — ปั๊มสารอาหาร A (เพิ่มค่า EC)
  • Pump B — ปั๊มสารอาหาร B (เพิ่มค่า EC)
  • Main Pump — ปั๊มหมุนเวียนน้ำในระบบ (ควรเปิดตลอด)
💡 ปั๊มหลักควรเปิดอย่างน้อย 15 นาที/ชั่วโมง เพื่อให้น้ำไหลเวียนและรากได้รับออกซิเจน
📋 Checklist ประจำวัน
  • ✅ เช็คระดับน้ำในถัง (ไม่ให้ต่ำกว่า 25%)
  • ✅ เช็คค่า EC และ pH (ปรับถ้าเบี่ยงเบน)
  • ✅ ดูสภาพใบ — ใบเหลือง? ใบม้วน? จุดสีน้ำตาล?
  • ✅ ดูราก — รากขาวสะอาด = ดี / รากน้ำตาล = ปัญหา
  • ✅ ตรวจสอบปั๊มทำงานปกติ
  • ✅ ดูอุณหภูมิน้ำ (ไม่เกิน 30°C)
🔧 แก้ปัญหาเบื้องต้น
อาการ สาเหตุที่เป็นไปได้ วิธีแก้
ใบเหลืองซีด ขาดไนโตรเจน / EC ต่ำ เพิ่ม EC ขึ้น 0.2-0.5
ปลายใบไหม้ EC สูงเกินไป ลด EC / เติมน้ำเปล่า
ใบม้วน pH ผิดปกติ / ร้อนเกิน ปรับ pH + ลดอุณหภูมิ
รากเป็นสีน้ำตาล รากเน่า (น้ำร้อน/เชื้อ) เปลี่ยนน้ำ + เพิ่มออกซิเจน
ต้นไม่ออกดอก EC ต่ำ / แสงไม่พอ เพิ่ม EC + เพิ่มแสง 12-16 ชม.
ดอกร่วง อุณหภูมิสูง > 35°C ลดอุณหภูมิ + เพิ่มการระบาย
